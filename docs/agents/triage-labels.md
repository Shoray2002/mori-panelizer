# Triage labels

Record the canonical role verbatim in the ticket's `Status:` line.

| Role | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Wayfinding ticket execution states are defined separately
in `issue-tracker.md`.
